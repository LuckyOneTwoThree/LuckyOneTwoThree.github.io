127 个源 Skill，覆盖四大领域：PM 106、UI 9、Backend 10、Cross-domain 2。

每个 Skill 是一个可独立执行的方法论 Pipeline；编排器负责调度子 Skill 和阶段卡口。四大领域通过**数据契约**衔接，从产品探索到上线运营形成闭环。

### 它是什么

- 127 个源 Skill，四大领域。
- 编排器 + 阶段卡口：每个阶段等待人类确认，再进入下一步。
- 12 条跨域数据契约流：PRD、定位、品牌、IA、用户流程、原型、设计令牌、页面清单、OpenAPI、架构、指标、埋点等。
- 兼容 Trae / Claude Code；支持自然语言、命令式、编排器三种调用。
- All-Skill Galaxy：力导向图谱呈现 127 个 Skill 的编排关系。

### 三个取舍

1. **AI 执行，人判断。** 阶段卡口不是流程冗余，是人机协作的分界线。
2. **契约驱动，不是自由聊天。** 跨域交接靠数据契约，减少信息断层。
3. **完整方法论，不是零散技巧。** 127 个 Skill 覆盖全生命周期，但部署和使用成本也随之上升。

### 证据

- 127 skills；4 大领域；12 条跨域数据契约流；MIT；Trae/Claude Code 兼容；Galaxy 可视化。
