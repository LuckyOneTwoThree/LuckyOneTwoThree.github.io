> _——当执行不再有摩擦力，我们去哪里寻找那场“美丽的误会”？_



过去大半年，创投圈和独立开发者社区里最性感的词，莫过于 OPC（One-Person Company，一人公司）。

伴随着各类桌面端 Agent 工具和多智能体框架的成熟，一种极具诱惑力的叙事开始流行：你不再需要寻找合伙人，不再需要忍受漫长的招聘和团队磨合。你只需要在本地起几个服务，配置好编排逻辑，就能拥有一个二十四小时待命的“硅基团队”。架构、前端、测试、增长运营，全由不同的 Agent 节点接管。一个人，一台电脑，就是一家独角兽的雏形。

作为一个每天都在重度使用 Agent 写代码、做产品的实践者，我对这种模式始终保持着克制的中立。

我不否认它在执行层面的降维打击。过去需要三个人对齐两天才能跑通的脚手架，或者需要反复拉扯的交互初稿，现在塞进工作流里，泡杯咖啡的工夫就能拿到一个完成度 80% 的交付物。在某些切面上，比如做一个年入百万美金的垂直工具、跑通一个确定性的流量套利闭环，全自动的一人公司就是最优解，它不需要多余的温情。

但如果把目光投向**非共识的创新**和**强体验驱动的产品**，事情就不一样了。当你连续几天坐在屏幕前，唯一高频交互的对象只有几个不断吐出字符的终端窗口时，一种很难用效率指标衡量的滞涩感会浮现出来。

植物学里有个很朴素的事实：树被风反复推搡，会把更多资源投向树干和根系，长得更粗、更稳；而被支架绑得太紧、一点都晃不动的树，撤掉支架后反而更容易倒伏或折断。这个机理最著名的样本是 Biosphere 2 的玻璃穹顶：里面的树少了风的推搡，木质更脆、更容易折断，研究者把原因指向“没有风”。（流传更广的版本说它们“长得更快、没成熟就倒”，细节被简化过，我不拿它当论据；但“缺风→木质变弱”这条机理有实验支持。）效率极高的温室，恰恰撤掉了让树干变硬的那股力。

我越来越确信，我们把 AI Agent 当成“团队”来组建一人公司时，也搭起了这样一座温室：产出的速度惊人，风却被挡在了外面。

我说的“风”，是两样东西：**有人在乎，以及现实有阻力。** “在乎”又分两层，一层来自另一个人，一层来自你自己；“阻力”则来自你手里的材料。而我所说的“火花”，是那个让你心里一动、并愿意为之下注的非共识念头，它多半就是被这两样东西点燃的。一人公司恰好把它们都稀释了。

这也是标题的意思。过去，执行是有摩擦的：要对齐，要交接，要在白板前争到面红耳赤。我们花了几十年想消灭它，Agent 几乎做到了。但“美丽的误会”，恰恰是这种摩擦的副产品。摩擦没了，误会发生的场合也就一起没了。

## 01 十面镜子：没有人会掀桌子的“群体智能”

很多推崇一人公司的玩家喜欢展示一种“赛博会议室”：给不同的 Agent 注入不同人设，一个激进的增长黑客、一个保守的架构师、一个挑剔的体验专家，让它们在共享上下文里互相辩论。

懂技术的人会反驳：这是你架构搭得不够好。现在可以异构模型混搭，Claude 主创、DeepSeek 审计，甚至引入红蓝对抗，强制设定零和奖励，逼着 Agent 互相挑刺。

这些都成立，而且确实能做出比人类同事更冷酷的**战术对抗**。但镜子的数量不是问题。**异质发生在“怎么说”，同质锁死在“为谁说”：** 不管底层是哪个模型，它们都在朝着让写下那段意图的人满意的方向优化。你以为在和十个专家头脑风暴，实际上只是把自己的想法扔进了十面曲率不同的镜子。

真实的合伙人不一样。Agent 可以挑出你代码里的一万个边界漏洞，但很少有一个 Agent 会在某个下午看着你说：“这个方案逻辑完美、数据也跑通了，可我突然觉得做这件事本身特没劲，把盘子掀了吧。”

严格地说，你让它质疑方向，它也能做到。区别在于：它的质疑是被要求的，归根结底，还是你的意志在借它的嘴说话；而合伙人的掀桌子来自一份独立的利害：他有自己的时间和名誉押在这件事上。这份利害让他的反对可信，也让他可能错得很真实，不少团队就死在这种冲动上。但这恰恰是重点：**一个有自己利害、会犯错的人，和一个永远合规的系统，提供的是两种完全不同的信息。**

人与人的沟通里，还有一种东西在 Agent 那里几乎消失了：**高带宽的意外。** 回想那些真正破局的瞬间，几乎没有哪个主意是按会议议程“推导”出来的。它往往诞生在结构化沟通之外：两个人下班路上吐槽一个离谱的需求；白板前争得面红耳赤时，某人因为没听清，基于错误的理解反驳了一句，这句“驴唇不对马嘴”的误读，恰好劈中了另一个人的盲区。

误读之所以有用，是因为两个独立的活人带着各自不可压缩的历史。在一人公司里，人与 Agent 的交互被压成“指令与响应”的低维通道，冗余、走神和误会都被当作噪音过滤掉了，藏在噪音里的灵感也一起被清理干净。

当然，绝大多数误会只是内耗，美丽的只是极少数，而你没法只订购后者。人很贵、很慢、很会消耗你，这正是一人公司的诱惑所在。但我的判断是：非共识创新的回报大概率是肥尾的，而那些离群的念头，更可能从这样的碰撞里冒出来。少数几次命中，就足以覆盖无数次内耗。对它来说，这笔钱值得付。

## 02 收敛是一种带代价的判断

接着是那个流传很广的说法：AI 只会插值，不会外推。我不认同。现代推理模型和带搜索的 Agent，完全可以向四周喷涌出成千上万个反常规、统计上概率极低的“离群点子”。

**AI 从不缺发散，缺的是那个为收敛付代价的人。**

它能瞬间给你一万种不重样的玩法，却不知道哪个是天才的疯子、哪个是电子垃圾。在围棋、编译通过、测试跑绿这类有可验证奖励的领域，评判标准明确，AI 的收敛能力极强；而在“好产品”“好旋律”“好交互”这类没有明确胜负的领域，标准只存在于人的共同体验里，而且常常是事后才被确认的。

人类的审美大半也是二手的，来自文化和他人。所以关键不在一手还是二手，而在于**有没有代价、有没有回路**。深夜连续三次编译报错的烦躁，上线前夕对未知市场的恐惧与狂喜，对某个拙劣设计的生理性厌恶，这些都在不断校准我们“什么值得在乎”。给人方向感的，是塔勒布所说的 Skin in the game：承担下行后果。这和前面那位掀桌子的合伙人的底气，是同一份东西：选错了要自己兜底，选对了功劳也是自己的，而且这笔账没有重置键，也没法中途退出。给 Agent 设计一套预算惩罚，和这种退不出的赌局，不是一回事。

人当然也常常收敛失败，尸横遍野的产品比比皆是。但那是我们自己的失败，会疼，会修正，会长进下一次的判断。

我不想证明 AI 永远收敛不好，也许哪天它接上真实的市场反馈，会长出自己的偏好，那是另一个话题。我在意的是眼下人这一端：收敛是一种带代价的判断，如果习惯了让算法先铺好四五个平滑的选项，自己只负责做选择题，这块“在乎的肌肉”就会在没有阻力的地方慢慢萎缩。

速度还在帮倒忙。过去执行很慢，慢本身就在逼人做判断：一套素材要画几周，想法会在这几周里被手艺、被反馈一遍遍捶打。Agent 把“做”变得几乎免费，却没有让“判断”变便宜。你早上冒出一个 60 分的念头，下午它已经成了一套体面的、能跑通的交付物。迭代当然可以更多，但如果每一轮都跳过了“这到底好不好”那一问，你只是在更快地生产没被审视过的平庸。80 分的成品尤其危险：它假装自己已经完成，替你把那次判断短路掉了。

## 03 消失的手感：从“与材料肉搏”沦为“云端甲方”

还有一个问题，和“有没有队友”无关，而和“有没有手”有关。

说到这个，我会想起我非常喜欢的一款游戏《星露谷物语》，和它的作者 ConcernedApe。他一个人包办了程序、美术、音乐和设计，做了四年半，技艺每有长进，就想把旧的东西重做一遍。他没有团队，但并非没有人：当时的女友用一份实验室技术员的工作撑着两个人的生活，他自己则兼职做剧院引座员；发行商在中途找上门，接手了发行和移植，而游戏本身，据他自己说，始终只有他一个人在做，玩家则在开发期就围了上来。当然，这样做的人很多，能走到这一步的凤毛麟角，他不是“独处必出杰作”的证据。但他提供了一个很清晰的样本：**他每天都在和物质世界与技艺本身肉搏。** 每一个像素的错位、每一段旋律的不和谐、每一处代码的报错，都是来自客观世界的阻力，而这些阻力反过来塑造了作品的棱角。

现代的一人公司热潮，很容易把创作者从这场肉搏里抽离出来，变成一个坐在云端的“甲方和审批员”：你不再敲代码，而是每天看 Agent 吐出完美的架构图；你不再琢磨交互细节，而是批阅几十份结构清晰的分析。这样，你同时失去了人类伙伴横向碰撞的“认知摩擦”，和手艺本身纵向抵抗的“材料阻力”，两头踏空。

我自己就正在经历这件事。最近我在做一首歌，风格参考我很喜欢的一首歌——Lauv 的《Paris in the Rain》。我让 AI 同步生成歌词和旋律，几轮下来，四五版方案都很完整：结构对，韵脚顺，情绪也合拍。可我听了一遍又一遍，挑不出毛病，却也没有一处让我心里一动。这大概是目前生成式 AI 做歌的普遍处境，更像在抽奖。

我并不是说 AI 给不出离群的东西。只是默认情况下，它给你的往往是最让人放心的那几版；要把它推到离群处，你得先知道自己想去哪，而“想去哪”，恰恰就是那份在乎。

那一刻我意识到，我一直在当评审，没有碰过旋律本身。所以我决定把这一块拿回来：关掉生成，自己对着手机哼。哼得很糙，但那段旋律里有一个转折，是我随口哼出来的，任何一版 AI 方案里都没有。

我不敢说它比 AI 的更好。人天然偏爱自己亲手做的东西，这有个名字，叫宜家效应。但我知道它是我的：AI 给的方案我随时可以换掉，而这个转折，我愿意为它辩护。同样是“舍不得”，两者并不一样：80 分的体面给人一种完成感，让人停步；一个粗糙却属于自己的转折，给人的是一种没做完的执念，逼人继续。当然，它也可能只是个平庸的转折，而我偏偏护着它。这就是代价，也是“下注”的起点。

需要诚实说明的是：这个问题不是一人公司独有的，它是**工具使用方式**的问题。同样用 Agent，保留亲手做的核心部分，阻力就还在。下面的“微型部落”能补上人与人之间的认知摩擦，而与材料的阻力，则必须靠每个人自己把手弄脏来守住。

## 04 微型部落：美丽的误会在哪里

写这些，不是要否定 Agent 的价值。把它们看作“认知的外骨骼”，帮我们扛起过去需要十个人才能背动的砖块，是大势所趋。但穿着外骨骼的人，不该把自己锁进一个只有机器轰鸣声的地下室。

所以回到标题的问题：去哪里寻找那场“美丽的误会”？我的答案是少数几个活人组成的“微型部落（Micro-Tribe）”，各自带着自己的 Agent。人数我没有精确的依据，直觉上是两三个到四五个：够多，足以产生真正的分歧；够少，对齐的成本还能靠一顿饭消化掉。

这里有一个陷阱：活人不自动等于多样。同校、同公司、同圈层的小团体，同样会同质化。部落真正的价值来自一种张力：**价值观相近，但生命经验差异很大。** 回头看 01 的镜子：十个 Agent 之所以是镜子，是因为它们共享你的意图，也共享你要讨好的对象。而好的部落成员，恰恰是那个价值观能对齐、经验却无法被压缩的人。前者让你们愿意一起下注，后者让碰撞里有缝隙可以透光。

它也不是灵药。找到这样的两三个人，比找一个普通合伙人更难；部落自己也会在舒服里退化成新的回音室。如果要给它一个粗糙的起点，我会从两条开始：第一，方向性的决定，必须摊开在一个有独立利害、有权随时掀桌子的活人面前，他的犹豫，权重要高于十个 Agent 的一致赞同；第二，Agent 负责“怎么做”，人保留“做不做”，以及“哪一块必须亲手做”的决定权。前者守住碰撞，后者守住手感。

在这样的部落里，确定性的、工程化的脏活累活交给各自的 Agent，人类伙伴把时间花在机器给不了的东西上：争吵，误解，抛出那些让大模型觉得“概率极低、毫无逻辑”的疯狂偏执，并为它们共同下注。

最后，我想把话说清楚。在事实层面，我愿意被说服：如果有一天，出现大量由一个人带着 Agent 做出的、被公认为非共识的、体验感极强的作品，而它们的作者说，那份碰撞并不必要，我会回来修改这篇文章。但有一部分，我不指望数据来裁决，因为这从来不只是一场效率之争。它也关乎我们想要什么样的创造：是一种把产出最大化的，还是一种有风的。

毕竟，Agent 已经替我们解决了“如何长得更快”的问题。而决定一棵树能不能站得住的，从来是那些没被算法抹平的阻力，以及屏幕对面那个同样有血有肉、愿意和你一起下注的活人。

温室不必拆。但总得有人，去把窗推开。
